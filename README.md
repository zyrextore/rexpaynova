# ZYREX PAY AI V3

Upgrade UI + dashboard + profile + transaction API.

## Fitur V3
- Mobile-first dashboard
- Quick actions
- Wallet & recent activity
- Transaction history API
- Profile API
- Search/filter UI
- Theme toggle
- AI workspace UI
- Notification center
- Security page UI
- Supabase Auth integration

## Setup
1. Edit public/config.js
2. Deploy repository ke Vercel
3. Tambahkan secret environment variables di Vercel
4. Jangan pernah masukkan secret key/payment key ke frontend

AI/payment action nyata tetap harus server-side dan divalidasi.
